# CodeKit 设计文档 v0.0.3

## 目标

优化 JSON 编辑器交互体验：

- 将原有的左右分栏（文本输入区 + 树形编辑区）改为**单区域重叠双窗口**
- 通过顶部按钮在两个窗口之间切换
- 两个窗口分别命名：**文本窗**、**编辑窗**
- 两个窗口共用同一套操作按钮
- 原"单行"按钮更名为"收起"

## 界面结构

### 布局变化

- v0.0.2：左右两栏并排（各 50% 宽度），左侧文本输入，右侧树形编辑
- v0.0.3：单区域，两个窗口重叠放置，同一时间只显示一个窗口

### 顶部工具栏（共用）

工具栏固定在顶部，包含两组元素：

1. **窗口切换标签**（左侧）
   - `文本窗`：显示 textarea 输入区
   - `编辑窗`：显示树形编辑区
   - 当前激活的标签高亮，点击切换下方显示的窗口
2. **共用操作按钮**（右侧）
   - `展开`：格式化 JSON（2 空格缩进），写入文本窗
   - `收起`：压缩 JSON 为单行（原"单行"按钮更名）
   - `示例`：加载预设示例数据
   - `清空`：清空所有内容
   - `复制`：复制当前数据到剪贴板
   - `自动换行`复选框：同时控制文本窗与编辑窗的换行行为

### 窗口区域（下方）

两个窗口在同一容器内重叠，通过 `display` 切换：

- **文本窗**：`<textarea>`，用于输入/查看 JSON 文本
- **编辑窗**：树状结构容器，支持折叠/编辑

切换窗口时，两侧数据保持同步（沿用 v0.0.2 的双向同步机制）。

## 功能细节

### 窗口切换

- 默认显示"文本窗"
- 点击标签切换窗口，仅切换显示，不丢失数据
- 切换时若编辑窗数据有更新，文本窗内容同步刷新

### 共用按钮行为

按钮根据**当前激活窗口**执行不同操作：

- **展开**：
  - 文本窗：格式化 JSON（2 空格缩进）写入 textarea
  - 编辑窗：展开所有树节点（递归收集所有 object/array 路径加入 expandedNodes）
- **收起**：
  - 文本窗：压缩 JSON 为单行写入 textarea
  - 编辑窗：收起所有子节点（清空 expandedNodes，仅保留根路径）
- **示例**：加载示例 JSON 到文本窗并解析，不切换窗口
- **清空**：清空 `currentData`、文本窗、编辑窗
- **复制**：
  - 文本窗：复制 textarea 当前内容（收起后是一行就复制一行）
  - 编辑窗：复制 `currentData` 格式化文本（2 空格缩进）
- **自动换行**：切换文本窗与编辑窗的换行模式
- **行号**（新增复选框）：切换文本窗与编辑窗的行号显示

### 编辑窗（树形编辑）

沿用 v0.0.2 的全部编辑能力：

- 折叠/展开节点
- 编辑 string/number 值
- 切换 boolean
- 改变 null 类型
- 重命名键名
- 添加/删除节点
- 编辑后同步刷新文本窗

### 文本窗（textarea）

沿用 v0.0.2 的输入解析能力：

- 输入事件 300ms 防抖触发解析
- 解析成功刷新编辑窗树
- 解析失败不自动切换窗口，左下角显示灯泡错误指示器

### 行号显示（新增）

勾选"行号"复选框后，文本窗和编辑窗均显示行号：

- **文本窗**：左侧 `.line-numbers` 列，按 `\n` 分割生成行号，与 textarea 同步滚动
- **编辑窗**：CSS counter 自动编号，`::before` 伪元素 absolute 定位至 tree-container 左侧对齐（不跟随树缩进），通过 JS 计算 `--line-offset` CSS 变量实现

### 错误指示器（新增）

- JSON 语法错误时，文本窗左下角显示 SVG 灯泡图标（`--vscode-errorForeground` 红色）
- 鼠标悬停灯泡时弹出错误详情（行号/列号/原因），离开自动隐藏
- 解析成功或清空时灯泡消失

### 树节点箭头位置

- 有 key 的节点：箭头放在冒号后（`features: ▶ [...] array`）
- 根节点（无 key）：箭头保持最前（`▶ [...] array`）

## 样式设计

- 窗口切换标签：激活态使用按钮背景色，非激活态使用 ghost 样式
- 重叠窗口容器：相对定位，两个窗口绝对定位填满容器
- 其余配色、字体沿用 VSCode 主题变量
